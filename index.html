About This Project

This AI Games Hub features multiple classic games and AI demos with a clean, professional interface. Each game showcases a core algorithm:

  • Tic-Tac-Toe: Minimax (unbeatable)
  • Maze Escape: DFS generation + A* pathfinding
  • Sudoku: Backtracking solver
  • N-Queens: Backtracking
  • Treasure Hunt: Q-Learning demo
  • Chess: Minimax with Alpha-Beta (requires python-chess on server)
